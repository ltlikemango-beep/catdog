# 毛球派对：猫狗弹射自用重建

这是重新编写的本地浏览器战斗原型。参考《狗狗呼叫喵星》的回合弹射与击落目标玩法，使用自行绘制的角色、场景和独立规则。没有运行原游戏代码、接入原服务器或复原其数值。

## 启动

需要 Node.js 18 或更新版本，不需要安装任何依赖。macOS 可以双击目录中的 `启动游戏.command`，自动启动并打开浏览器；关闭对应终端窗口即可停止服务。也可以手动运行：

```bash
git clone https://github.com/ltlikemango-beep/catdog.git
cd catdog
npm start
```

浏览器打开 http://127.0.0.1:4173 。默认仅监听本机。支持两人在同一设备上轮流操作，暂不支持两台设备联机。服务器部署可以通过 `HOST` 和 `PORT` 环境变量设置监听地址和端口，见 [部署说明](DEPLOY.md)。

## 怎么玩

- 每队三只角色，每回合选一只角色发射一次，发射结束后交换操作。
- 在己方角色上按住，向敌人相反方向拉，松手发射。向下拉可提高仰角。虚线只展示前段预测弹道。
- 也可用角度、力度滑条和“发射”按钮；未聚焦控件时，数字 1、2、3 切换角色，空格发射。
- 角色生命归零，或绳索耐久归零，就会落水出局。先打落对方全部角色获胜。
- 骨头弹速度较慢，可一发击断绳索；鱼鱼弹伤害较低，但能波及附近敌方角色和绳索。
- 当前无风力、地形碰撞和友伤；场景岛屿为装饰。没有回合倒计时。音效可手动开启。

## 联机实现方向

保留与界面分离的 `dist/engine.mjs` 战斗规则。下一阶段由一个服务进程保存房间状态并运行固定步长模拟，客户端只提交选角和发射参数，服务器校验轮次、归属和参数范围后广播状态。通过房间码加入，补齐断线快照与重连，再测试两个客户端是否看到一致结果。不要仅在两个浏览器中各自运算物理并假设结果相同。

本版坐标为 1200 × 650，固定物理步长 1/120 秒。角色生命 100、绳索耐久 60；所有参数集中在 `engine.mjs`，便于试玩后调整。

## 验证

```bash
npm test
```

测试覆盖高速炮弹碰撞、绳索破坏、范围伤害、回合切换、终局、边界发射和重置等核心规则。界面由 `dist/index.html`、`style.css`、`app.mjs` 和 `renderer.mjs` 组成，不依赖外部字体、图片或网络资源。

2026-10-30 验证记录：8 项核心规则测试通过，包括用实际飞行模拟打完整局。浏览器实测按钮发射击断绳索、拖拽发射命中扣血、双方轮流操作、禁用出局角色、帮助弹窗和重新开局；桌面 1280 × 800、窄屏 390 × 844 均已检查，未发现脚本错误或横向溢出。尚未在触屏设备上实测，也未实现跨设备联机。

## 仓库说明
